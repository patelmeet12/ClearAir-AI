# ClearAir AI — Artificial Intelligence Architecture & Integration

## Dual-Engine AI Design

ClearAir AI features an extensible, dual-tier intelligence architecture:

```
                                  User Query / Action
                                          │
                                          ▼
                       Is GenAI enabled AND has API key?
                                  /               \
                             YES /                 \ NO (or failure)
                                ▼                   ▼
                   ┌──────────────────────┐  ┌───────────────────────────┐
                   │ Genuine GenAI Engine │  │ Deterministic Local Engine│
                   │ (Gemini 1.5 Flash)   │  │ (Rule-Based Expert Model) │
                   └──────────────────────┘  └───────────────────────────┘
                                │                   │
                    Label: [GenAI Active]    Label: [Deterministic Local]
                                │                   │
                                └─────────┬─────────┘
                                          ▼
                         Validated Structured Response
                         1. Explanation
                         2. Recommended Actions
                         3. Why It Matters
                         4. Estimated Affordability
                         5. Expected Benefit & Uncertainty
                         6. Scientific Evidence Reference
                         7. Clinical Escalation Notice
```

---

## 1. Genuine GenAI Provider (Gemini 1.5 Flash)

When the user configures their Gemini API key and enables GenAI in the Settings screen:
- Requests are dispatched directly to the Google Generative Language API endpoint (`models/gemini-1.5-flash:generateContent`).
- Context injection: The prompt injects real-time local AQI, dominant pollutant concentrations, temperature, household demographics (kids, seniors, sensitivities), and budget tiers.
- JSON mode schema enforcement: The response is guaranteed to conform to the 7-part structured advice schema.
- **Fail-Safe Fallback**: If the network times out (> 12 seconds), the API returns a rate-limit error, or the key is invalid, the engine silently falls back to the deterministic local assistant.

---

## 2. Deterministic Local Assistant (Demo Mode)

Per project guidelines:
> *"Provide a clearly labeled Demo Mode with deterministic local recommendations when no real AI service is configured. Never claim that rule-based recommendations are generated by an actual LLM."*

When GenAI is unconfigured, ClearAir AI runs its embedded deterministic environmental expert model:
- Explicitly labeled in the UI as **`[Deterministic Local Assistant | GenAI unconfigured]`**.
- Scientifically validated decision trees covering:
  * Hazardous smog child safety and outdoor recess cancellations.
  * In-cabin vehicle HVAC recirculation and cabin filter recommendations.
  * Low-cost DIY Corsi-Rosenthal boxes vs. commercial HEPA air purifiers.
  * Houseplant myth debunking (referencing the 2019 Drexel University meta-analysis).
  * Senior cardiovascular safety during thermal inversion windows.

---

## 3. "Why This Matters" Impact Explainer

When users complete a daily routine or adopt a sustainable alternative, the AI Impact Explainer provides an evidence-based breakdown:
- **What Changed**: Specific behavioral adjustment (e.g., trip chaining or anti-idling).
- **Personal Exposure Reduction**: Reduced lung deposition of PM2.5 and black carbon during rush hours.
- **Environmental Emission Avoided**: Calculated grams of PM2.5 and kilograms of CO2e avoided.
- **Model Assumptions**: Documented fuel consumption factors (12.5 km/L baseline, 1.2 L/hr idle fuel burn).
- **Limitations of Estimate**: Transparent disclosure that actual benefits vary based on vehicle curb weight, engine displacement, and local electric grid mix.
